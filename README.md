# حَراك — Harak

تطبيق تدريبٍ شخصي عربي `RTL` يعمل على الجوّال كـ`PWA` بلا إنترنت، مبنيٌّ على **أنماط الحركة** لا على التمارين: ثمانية أنماط تغطّي الجسم كلّه، وكل نمطٍ يُنفَّذ بأي أداةٍ متاحة — وزن الجسم، أوزان حرّة، أو ماكينة.

يبني التطبيق دورةً تدريبية كاملة بمنهجيةٍ علمية (`WHO 2020`، حجم `10–20` مجموعة/عضلة/أسبوع، تكرار `2×`، ضبط الجهد بـ`RIR`، تقدّم مزدوج، تفريغ دوري)، ويقود الجلسة، ويسجّلها، ويرفع الحِمل تلقائياً، ويعرض التقدّم.
